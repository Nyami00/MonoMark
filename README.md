# MonoMark

**Markdown Viewer & Editor** - ブラウザだけで動くシンプルなMarkdownビューア&エディタ

## Demo

**https://nyami00.github.io/MonoMark/**

## Features

- `.txt` / `.md` ファイルの読み込み（ドラッグ&ドロップ対応）
- リアルタイム編集 & プレビュー（リサイズ可能な分割画面）
- シンタックスハイライト付きコードブロック
- ライト / ダーク テーマ切替
- カスタマイズ可能な表示設定（フォント、サイズ、色、レイアウト等）
- 設定のJSON書き出し / 読み込み
- HTMLエクスポート（スタイル込み）
- LocalStorageによる状態の自動保存

## Usage

1. 上記のDemo URLにアクセス、または `index.html` をブラウザで直接開く
2. テキストファイルをドラッグ&ドロップ、またはエディタに直接入力
3. 右側にリアルタイムでプレビューが表示されます

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Ctrl+O` | ファイルを開く |
| `Ctrl+S` | Markdownを保存 |
| `Ctrl+,` | 設定パネル開閉 |

## Data Privacy

**このアプリケーションはユーザーのデータを一切収集・送信しません。**

- すべての処理はブラウザ内で完結します（クライアントサイドのみ）
- 外部サーバーへのデータ送信は行いません
- ファイルの内容はブラウザのLocalStorageにのみ保存され、端末外に出ることはありません
- 読み込んだデータの二次利用は一切行いません
- 安心してご利用ください
